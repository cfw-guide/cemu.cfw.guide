Installing Games

If you need further help, ask on the official Cemu Discord Server for assistance.

This page will take you through the installation of decrypted game dumps in Cemu. If you dumped the Friend List application earlier, you can install it like any other dump under "Installing dumps".

If you have an encrypted game dump , you may need to decrypt it using CDecrypt. If you used dumpling to get your dump, you will not need to do this.

Installing titles

If you have dumped your account data and online files to install an eShop title, follow the "Downloading from eShop" tab to download and install your game. If you have a disc game dump, you can install it through Cemu in the "Installing dumps" tab.

  1. Open the Cemu application
  2. On the top bar, click Tools → Download Manager
  3. Select your account, then click "Connect"
  4. Right click on the title you want to install, and click "Download"
  5. Repeat this for any updates and DLC you want to install

Once installed, you should be able to launch the title from the Cemu menu.

Installing dumps

  1. Open the Cemu application
  2. On the top bar, click File → Install game title, update or DLC
  3. If you used Dumpling to dump your game, navigate to the dumpling folder on your SD card or USB storage device
    • If you used an alternative dumping tool, navigate to the folder where you keep your game dumps
  4. Open the relevant folder corresponding the content you want to install
    • In Dumpling, this is either the Games, Updates or DLC folder
  5. Open the folder of the game, update or DLC you would like to install
  6. Open the meta folder and select meta.xml
  7. Cemu should now automatically install the files for you

Repeat this as many times as you need until everything you dumped is installed.

Linux users may have issues installing updates/DLC. You may have to extract the title directly to the installation directory: mlc01/usr/title. If using Lutris, please read the notes under the script provided.

Transferring saves

  1. Open the Cemu application
  2. Right click on the game you would like to transfer the save to
  3. Click "Save directory"
  4. If you used Dumpling, open the dumpling/Saves/[Game Title] folder from your SD card or USB storage device
    • If you used an alternative dumping tool, navigate to the folder where you keep your save backups
  5. Copy and paste the contents to the save directory you opened from Cemu

Installing updates and DLC

Instead of dumping it from your Wii U, it may be a lot faster to install them directly to Cemu from the eShop. If you dumped your online files using dumpling, you can follow the instructions in the "Downloading from eShop" tab to install any updates or DLC.

You should now have all the games you dumped installed onto Cemu.

Some games, such as Breath of the Wild, require an update to be installed to be functional in Cemu.
